# Калькулятор вкладов

Одностраничное веб-приложение для расчета доходности банковского вклада с ежемесячной капитализацией. Проект демонстрирует навыки создания REST API на Java Spring Boot и SPA-приложения на React + TypeScript.

## Cтек

**Backend:**
* Java 21
* Spring Boot (Web, Validation)
* Maven
* BigDecimal (для точных финансовых вычислений)

**Frontend:**
* React 
* TypeScript 
* Vite 
* Native Fetch API 
* CSS3 (Flexbox)

## Функционал и архитектурные решения

* **Слоистая архитектура:** разделение на Controller, Service и DTO.
* **Валидация данных:** проверка входных данных на бэкенде и на фронтенде.
* **Точность вычислений:** использование `BigDecimal` с `MathContext` и `RoundingMode` для исключения ошибок округления
* **Безопасный CORS:** настроен через Vite Proxy для корректной работы фронтенда с бэкендом при локальной разработке.
* **Обработка состояний:** загрузка, ошибки сервера и успешный результат отображаются корректно.
* **Форматирование:** вывод сумм через `Intl.NumberFormat` (форматирование под валюту РФ).

## Как запустить

Для запуска потребуется **JDK 21+** и **Node.js 18+**

### 1. Запуск Backend
```bash
cd backend
./mvnw spring-boot:run
```

Сервер запустится на http://localhost:8080

### 2. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```
Приложение откроется на http://localhost:5173
